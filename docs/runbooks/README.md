# Runbook Index

Store operational runbooks in this directory, grouped by service or workflow (e.g., `nginx/deploy.md`, `kubernetes/incident-response.md`). Each runbook should include prerequisites, safe-guarded commands, and post-checks so the agent can execute or escalate actions responsibly.

Current stubs include:
- `nginx/deploy.md` — чеклист выпуска NGINX.
- `kubernetes/rolling-update.md` — пошаговый rollout в Kubernetes.
- `vm/maintenance.md` — регламент на обслуживание VM-флотов.
