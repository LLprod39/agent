# VM Maintenance Window

1. Подтвердите окно и уведомите заинтересованные команды.
2. Выполните проверку доступа: `ssh <bastion>`, затем `ssh <target>`.
3. Снимите метрики перед началом (`collectd`, `prometheus-node-exporter`).
4. Примените патчи/обновления, руководствуясь автогенерированным планом агента.
5. Перезагрузите сервисы и сравните метрики с базовой линией.
