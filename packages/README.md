# SDK Packages

This area houses automation SDKs and shared schemas that external systems use to integrate with the DevOps agent.

- `sdk-python/` will provide a typed Python client and helper utilities.
- `sdk-typescript/` exposes the same capabilities for Node.js and browser consumers.
- `shared/` contains cross-language artefacts such as JSON Schemas and protocol definitions (see `env_schema/`).

Document notable API changes in `DevOps_LLM_Agent_Plan.md` and the SDK-specific READMEs as functionality lands.
