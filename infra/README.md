# Infrastructure Code

Infrastructure-as-code assets live under this directory.

- `terraform/` holds reusable modules and environment definitions.
- `helm/` tracks Helm charts and values for Kubernetes deployments.
- `compose/` captures local Docker Compose scenarios for developer workflows.

Document new environments and rollout procedures in `docs/runbooks/` and keep `DevOps_LLM_Agent_Plan.md` updated when structure changes.
